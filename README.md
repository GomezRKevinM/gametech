# gametech

## Proposito

El proposito de este proyecto es poner en practica lo aprendido en el bootcamp y divertirnos.

# 🎮 Juego:

## Papel Piedra o Tijera

### Instrucciones:

- Tenemos que construir un html basico donde el usuario pueda jugar el clasico juego de **Piedra papel o tijera**

- Es necesario crear un evento para dar inicio a la partida.

- Tambien es necesario crear una función para que haga las elecciones de la maquina.

- Por ultimo tendremos que organizar la relevancia de cada selección para imponer a un ganador.
